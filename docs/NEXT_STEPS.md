# 第一轮交互调整清单（历史记录，2026-10-28）

以下是开发阶段保留的需求和交接记录，十项调整现均已实现，不是当前待办。用户后来已授权以 nook（星择）0.1 打包、安装及开源；系统默认关联和 niri 配置仍未修改。当前使用与构建方式见根目录 README，验证范围见 [VALIDATION.md](VALIDATION.md)。

## 用户要求的 10 项调整

1. **空格切换预览**：选中文件按空格打开预览；预览打开期间再按一次空格关闭。Esc 仍可关闭。避免按键自动重复造成连续开关，并确保输入框编辑、输入法组词期间不拦截空格。
2. **列宽拖动与两种记忆方式**：鼠标左键按住列表表头各列边缘可拖动调整宽度。既支持保存用户自定义列宽，也保留只对当前进入有效、再次进入目录恢复默认宽度的临时模式。需要明确易懂的保存/临时切换和恢复默认入口，不能只实现永久保存。
3. **精简左侧磁盘**：仅保留一个 Linux 盘，以及从 Windows 分出来的三个用户盘，共四项。先只读核实真实分区、标签和挂载情况；不要把 Btrfs 子卷、/srv、/var/log、EFI、恢复分区等重复罗列，也不要擅自挂载或猜测三个 Windows 用户盘。
4. **预览可调整大小**：预览浮层的边缘/角可拖动改变大小，设置合理最小/最大尺寸，保持内容可滚动；不能让窗口、操作按钮或文件内容超出主窗口可见范围。
5. **右键菜单重设计与功能**：改进视觉、字号、间距、圆角、图标和层级；添加“将文件夹加入左侧快速访问”；提供“打开方式”二级菜单，列出适用系统应用；提供独立“彻底删除”入口，直接删除、不进回收站，并保留明确的不可恢复确认。
6. **深色选中高亮**：当前选中态不明显，提升对比度，可使用淡紫色；区分悬停、选中和当前焦点，并保证文字可读。
7. **设置界面重设计**：当前布局和组件过于简陋，改进分组、留白、层级、组件和审美。右键菜单和设置可参考下列网站/仓库的视觉，不因此引入 React/浏览器运行时；参考代码或素材前另查许可。
   - https://www.reactbits.dev/ ，源码 https://github.com/DavidHDev/react-bits
   - https://bencho.dev/blocks ，用户链接目标 https://bencho.dev/
   - https://github.com/starc007/ui-components
8. **更换文件夹图标**：现有文件夹 SVG/ico 不美观，换成更精致、与界面一致的文件夹图标；核实素材许可或独立绘制，并验证各缩放比例。
9. **加快滚轮滚动**：文件列表、网格及对应可滚动界面的滚轮步长太小，增大每个滚轮刻度滚动距离；兼顾高分辨率触控板，不把两者都生硬放大。
10. **调整按钮位置**：刷新按钮移到“上一级”按钮的右边；“新标签页”按钮移到现在刷新按钮所在位置，即地址栏右侧原刷新位置。

## 必须保留的已有约束

- 文件名字号默认 15 个逻辑像素，元信息不低于 12，标签文字 14；使用系统字体与原生 Wayland 缩放。
- 字符、图标、文字与 UI 边框协调，不越界、不互相挤压；测试窄窗口、长中文文件名、双栏、弹窗及 100%/125%/150% 缩放。
- 标签页已修正为在 48 像素高顶部栏中垂直居中，标签本体 36 高，上下各 6 留白，不能回退为 ListView delegate 固定 y 偏移。
- 技术栈继续 Qt Quick/QML + C++20 + GIO + SQLite，注意空闲 CPU、内存、虚拟列表、取消、限并发；不引入网页运行时来照搬参考网站。
